# Kosmedix Shop

A static, mobile-first shop page of trending beauty products (data from the "Kosmedix Shop" Notion database, October 2026).

- `index.html` – the site (data is inlined; no build step needed to view it)
- `products.json` – product data exported from Notion
- `img/` – product images (from each product's page or the brand's official listing)
- `build.py` + `src/template.html` – optional: rerun `python3 build.py` after editing `products.json`
